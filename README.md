# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built using Python and Streamlit.

## 📌 Features

- 📄 Upload your resume in PDF format
- 📝 Extract text from the resume
- 🔍 Detect technical skills
- ✅ Display skills found in the resume
- 💡 Give suggestions for missing skills
- 🌐 Deployed using Streamlit Community Cloud

## ⚙️ How to Run Locally

### 1. Clone the repository

git clone https://github.com/Mohammad-Fazila/AI-Resume-Analyzer.git

### 2. Open the project folder

cd AI-Resume-Analyzer

### 3. Install the required libraries

pip install streamlit pypdf

### 4. Run the application

streamlit run app.py

## 🎯 Project Goal

The goal of this project is to help users quickly analyze their resumes and identify technical skills included in their resume.
